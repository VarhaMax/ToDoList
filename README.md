# TO-DO LIST
A simple, intuitive to-do list made using agent-based programming. This project is designed to help users manage their tasks efficiently and effectively.
## Features
- Add, edit, and delete tasks
- Mark tasks as complete or incomplete
## Limitations
- No way to directly edit a task
- No form of prioritization for tasks
# Running
To run the application, follow these steps:
1. Clone the repository to your local machine.
2. Open the project within your IDE and using it's built-in terminal, run the following command:
   `dotnet run --project csharp-implem/ChecklistConsole/ChecklistConsole.csproj`
